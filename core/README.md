# USD Core Specification

The **USD Core Specification** defines the foundational data model,
composition semantics, file formats, and schemas of Universal Scene
Description (USD). It is developed by the Alliance for OpenUSD
(AOUSD) and is the normative reference for interoperable USD
implementations.

## Supplemental Materials

Sample implementations of spec-defined behavior and the framework
used to assess compliance with the USD Core Specification are
maintained in a companion repository:
[`core-spec-supplemental-public`](https://github.com/aousd/core-spec-supplemental-public).

## Citing a Release

Citations should include the specification name and version (for
example, `USD Core Specification v1.0.1`). The source commit hash
appears in each release's document subtitle for reproducibility. The
stable URL of either artifact in this directory is the recommended
citation link.
